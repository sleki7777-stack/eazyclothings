# EAZY ZI — Master Project Consolidation

This folder is the EAZY project intelligence/consolidation layer.

It preserves the decisions, standards, architecture, commerce rules, sourcing rules, AI/control-plane direction, and lab checklist established before final local testing and deployment.

## Core rule

**WHAT THE CUSTOMER SEES AND CHOOSES IS EXACTLY WHAT THE CUSTOMER GETS — 100%.**

No generated, recoloured, substituted, editorial, or placeholder image may be presented as a real purchasable product.

## Brands

- **EAZY / EAZY Clothing Exquisites** — garments, textiles, full looks, commissioning and clothing.
- **SLEEK EAZY** — premium accessories and completion pieces.

## Current phase

**CONSOLIDATE → POWERSELL LAB → VERIFY → FIX → ONLY THEN DEPLOY**

Current development workflow is local **PowerShell**. Vercel is not the current development environment.
